쿠키상점 개인정보처리방침

시행일: 2026년 11월 10일 · 서비스 운영자는 게시 전에 실제 운영 방식 및 연락 방법을 확인해 주세요.

쿠키상점은 학급 내 쿠키 보유량과 간식 구매 내역을 관리하는 웹앱입니다. 사용자가 선택하여 Google 계정을 연결하는 경우, 데이터의 저장과 불러오기를 위해 Google Drive API를 사용합니다.

1. 처리하는 정보와 목적

  • 학급의 상점 이름, 학생 번호·이름, 쿠키 수량, 간식 메뉴와 가격, 구매·환불·장부 기록: 상점 운영과 동기화
  • 사용자가 입력하는 다했니 API Key 및 학생 코드: 다했니 서비스에 학생 쿠키 정보를 요청할 때 사용
  • Google 계정 승인으로 부여되는 인증 토큰: 요청한 Google Drive 기능 수행에만 사용

2. Google Drive 접근 범위

앱은 사용자의 동의에 따라 Google Drive의 앱 전용 숨김 저장공간(appDataFolder)에 쿠키상점 설정과 기록을 저장·불러옵니다. 앱 전용 저장공간 권한은 사용자의 일반 Drive 문서와 사진 전체를 열람하는 권한이 아닙니다. 앱의 접근은 사용자가 허용한 범위로 제한됩니다.

3. API Key 저장과 암호화

사용자가 API Key 암호화 저장을 선택하면, 입력한 암호를 이용해 브라우저에서 암호화한 데이터가 Drive에 보관됩니다. 암호화 암호를 잃어버리면 해당 키 복원이 어려울 수 있습니다. 암호화하지 않는 옵션을 선택하면 API Key가 암호화되지 않은 채 앱 저장 데이터에 포함될 수 있으므로 권장하지 않습니다.

4. 보관과 삭제

Google Drive의 앱 전용 데이터는 사용자의 Google 계정에 저장되며, 사용자가 데이터 삭제를 수행하거나 Google 계정의 앱 접근 권한을 철회할 수 있습니다. 단순 로그아웃만으로 Drive에 저장된 파일이 자동 삭제되는 것은 아닙니다. 학생 정보 입력 및 보관 기간은 실제 학급 운영 정책에 따라 관리해야 합니다.

5. 제3자 및 외부 서비스

Google Drive 저장·불러오기를 위해 Google API와 통신하고, 다했니 연동 기능을 사용하면 입력된 학생 코드와 API Key로 다했니 API에 요청합니다. 앱 운영자가 별도의 서버로 사용자 Drive 파일 전체를 수집한다는 의미는 아닙니다. 웹사이트의 실제 배포 코드 및 외부 라이브러리 구성을 검토해 이 안내와 일치하도록 유지해야 합니다.

6. 안전한 사용

학생 개인정보가 포함될 수 있으므로 교사용으로 관리되는 계정을 이용하고, 공용 기기에서는 사용 후 로그아웃하세요. 연결한 Google 계정과 암호화 비밀번호를 타인과 공유하지 마세요.

7. 문의

개인정보 관련 문의는 쿠키상점 운영자에게 전달해 주세요. [게시 전 운영자 연락처 또는 문의 방법을 반드시 기입하세요.]
