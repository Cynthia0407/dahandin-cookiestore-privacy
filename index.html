쿠키상점 소개
쿠키상점은 교사들이 학급의 쿠키와 간식 상점을 쉽고 편리하게 관리할 수 있도록 개인 개발자가 만든 무료 교육용 도구입니다. 학생별 쿠키 잔액과 간식 메뉴, 할인, 구매·환불 내역을 관리할 수 있으며, Google Drive 동기화를 이용하면 본인의 Google 계정에 상점 데이터를 저장하고 다른 기기에서 이어서 사용할 수 있습니다.

쿠키상점은 교사 등이 학급의 쿠키 잔액, 간식 메뉴, 할인 설정, 구매·환불 내역 등을 관리할 수 있도록 개인 개발자가 제작한 웹 애플리케이션입니다. 특정 학교, 교육청 또는 교육기관이 공식적으로 제공하거나 보증하는 서비스가 아닙니다. 이용자는 본인이 소속된 학교·기관의 개인정보 처리 기준과 지침을 확인한 후 서비스를 이용해야 합니다.

3. Google 로그인 및 Drive 접근 범위

Google 로그인 후 쿠키상점은 https://www.googleapis.com/auth/drive.appdata 권한을 사용하여 Google Drive의 앱 전용 데이터 영역(appDataFolder)에 파일을 저장하고 불러옵니다. 이 권한은 쿠키상점 앱의 전용 데이터 영역에 한정되며, 일반 Google Drive에 있는 이용자의 문서·사진 등 전체 파일을 검색하거나 열람하기 위한 권한이 아닙니다.

  • 각 이용자는 자신의 Google 계정으로 로그인하고 자신의 앱 전용 저장공간에 데이터를 저장합니다.
  • 이용자별 Google 계정의 저장 데이터는 서로 자동 공유되지 않습니다.
  • 운영자는 쿠키상점 자체 서버에 이용자의 상점 데이터 사본을 수집·보관하는 별도 백엔드를 운영하지 않습니다. 다만 GitHub Pages, Google 및 다했니 등 외부 서비스는 각자의 서비스 제공 과정에서 접속·기술 정보를 처리할 수 있습니다.
  • OAuth 접근 토큰은 브라우저에서 Google API 요청을 수행하는 데 사용됩니다. 서비스 코드상 토큰을 상점 데이터 파일에 포함해 Drive에 저장하지 않습니다.

4. 저장 데이터 및 API Key 암호화

  • 상점 이름, 학생 명단·코드, 학생별 쿠키 정보, 메뉴·할인 설정 및 판매 장부는 이용자 본인의 Google Drive 앱 전용 저장공간에 저장됩니다. 이 상점 데이터 전체가 앱 자체 암호화되는 것은 아닙니다.
  • 다했니 API Key 암호화 옵션을 켜면 브라우저에서 PBKDF2(SHA-256, 250,000회 반복)로 암호화 키를 유도하고 AES-256-GCM으로 API Key를 암호화한 뒤 암호문을 Drive에 저장합니다.
  • 암호화 비밀번호는 Drive나 서비스 운영자에게 전송·저장되지 않습니다. 다른 기기에서 API Key를 복호화할 때 동일한 비밀번호가 필요하며, 비밀번호를 잊으면 저장된 암호문에서 API Key를 복구할 수 없습니다.
  • 암호화 옵션을 끄면 API Key가 암호화되지 않은 상태로 Drive 앱 전용 저장공간에 저장될 수 있으므로 권장하지 않습니다.
  • 암호화 옵션은 다했니 API Key에만 적용됩니다. 학생 정보, 학생 코드, 쿠키 잔액, 구매·환불 장부 등 나머지 상점 데이터는 별도로 암호화하지 않습니다.

5. 다했니 API 및 외부 서비스 이용

이용자가 다했니 API 조회 기능을 실행하면 브라우저는 입력된 학생 코드와 API Key를 사용하여 다했니 API에 요청을 보냅니다. 학생 코드가 조회 요청에 포함되고 API Key는 요청 인증 정보로 사용됩니다. 이 과정에는 다했니 서비스의 정책과 이용 조건이 적용됩니다.

Google Drive 저장·불러오기 요청은 Google API로 직접 전송됩니다. 쿠키상점 운영자는 이용자의 Google Drive 파일을 직접 열람하는 기능이나 별도의 데이터 수집 서버를 운영하지 않습니다. GitHub Pages, Google, 다했니 등 외부 서비스의 개인정보 처리에 관해서는 각 서비스 제공자의 정책을 확인해 주세요.

6. 보유 기간, 연결 해제 및 데이터 삭제

Drive에 저장된 상점 데이터는 이용자가 해당 파일을 삭제하거나 관련 Google 계정의 앱 데이터 관리 절차를 통해 삭제할 때까지 남아 있을 수 있습니다. Google 로그인 해제, 로그아웃 또는 OAuth 접근 권한 철회는 Drive에 저장된 파일 자체의 삭제와 다릅니다.

현재 버전의 삭제 기능 안내
현재 쿠키상점 버전에는 Google Drive 앱 전용 저장 파일을 앱 화면에서 직접 영구 삭제하는 기능이 제공되지 않습니다. 운영자는 이용자의 앱 전용 저장공간을 직접 열람하거나 대신 삭제할 수 없습니다. 저장 파일 삭제가 필요한 경우 Google 계정의 앱 데이터 관리 절차를 확인해야 합니다. 권한 철회만으로 데이터가 삭제된다고 보장하지 않습니다.

이용자는 학생 정보 등 개인정보가 포함된 데이터를 목적에 필요한 기간 동안만 보관하고, 더 이상 필요하지 않은 정보는 소속 기관의 기준과 관련 법령에 따라 삭제해야 합니다.

7. 학생 정보 및 이용자 책임

학생 이름, 번호, 학생 코드, 쿠키 잔액 및 구매 기록은 개인정보에 해당할 수 있습니다. 쿠키상점은 개인 개발자가 제공하는 도구이며, 각 교사·이용자가 학생 정보를 입력하고 관리하는 구체적인 목적과 권한은 이용자 및 소속 학교·기관의 상황에 따라 달라집니다.

  • 이용자는 소속 학교·기관의 개인정보 보호 지침과 관련 법령을 확인하고, 필요한 승인·안내·동의 절차를 거쳐야 합니다.
  • 교육 목적에 필요한 최소한의 학생 정보만 입력하고, 불필요한 민감정보나 고유식별정보를 입력하지 마세요.
  • 가능하면 교사용으로 관리되는 Google 계정을 사용하고, 공용 기기에서는 사용 후 로그아웃하거나 연결을 해제하세요.
  • API Key와 암호화 비밀번호를 타인과 공유하지 말고, 기기와 계정의 보안을 유지하세요.
